⌨️ Key Script - Keyboard Automation & Gaming Macro Tool
Key Script is a lightweight, fast, and reliable keyboard automation tool built in C# using the Windows API. Designed specifically for PC gaming and repetitive keypress actions without input lag, freezing, or background interference.

🇬🇧 English
✨ Key Features
Keyboard Focused: Full support for standard keys (A-Z) with maximum stability and no input lock.

Emergency Panic Button: Instantly stop all active macros with a single emergency keypress.

Auto-Save System: Automatically saves and restores your configurations upon restarting.

Low Latency & Lightweight: Ultra-fast response time with minimal CPU and RAM footprint.

Open Source: Clean, structured C# source code ready for customization.

🤖 Built with AI
Note: This project was developed and engineered with AI Assistance, optimizing WinAPI integration, UI responsiveness, and execution stability.

🚀 Quick Start
Clone or download this repository.

Open the project in Visual Studio.

Build the solution to generate the executable (.exe).

زر الطوارئ (Panic Button): إيقاف فوري وشامل لكل الأوامر بنقرة زر واحدة لضمان الأمان أثناء اللعب.
